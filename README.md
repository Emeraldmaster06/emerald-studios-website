# Emerald Studios Website

Portrait, event and wedding photography website for Emerald Studios, Sydney.

## Branches

- **Website-Page** — the website pages (`index.html` is the current site, live at https://emerald-studios-photography.com; `site/earlier-version.html` is the earlier design). Each page is self-contained: open it in a browser to view it.
- **Photos** — all images used on the website, saved as separate files under `photos/`.
